What this page does

It puts custom firmware with new features on your Circuit Mono Station.

  • Firmware: flash a modified firmware, or go back to stock 1.2.
  • Firmware settings: adjust the mods, such as the drive amounts.
  • Packs: back up patches and sessions, or send a .monostationpack to the unit.

It all runs in this browser, over USB MIDI; files you choose stay on your computer.

1. Stock firmware

Choose Novation's stock firmware 1.2, monostation-firmware-800.syx; the page builds the modified firmware from it. Any other .syx is flashed as it is.

2. Firmware to flash

Choose the stock file first.

3. Flash

Connect the unit by USB and switch it on. Allow MIDI access with SysEx when asked.

  1. Switch the Mono Station off.
  2. Hold Scales + Note + Velocity.
  3. Switch it on, then let go.

Back up the unit

Reads the unit's 64 patches and 32 sessions and saves them as a .monostationpack that Components can open. The unit restarts into its bootloader for this and comes back by itself; it takes about half a minute.

Send a pack

Choose a .monostationpack or a .syx of patches, tick what to send and where it goes. The unit restarts into its bootloader, stores everything, reads it back to check and comes back by itself.

Mod settings

Mod settings

Settings of the mods in the firmware on the unit. Changes are heard at once; Save keeps them after power-off. Stock firmware has none.

Save and Reset restart the unit into its bootloader for a few seconds to write the settings, then it comes back by itself.

Which browsers work?

Firefox and Chromium on the desktop are tested; Chrome, Edge and other browsers built on Chromium should work too. Safari and browsers on iPhone and iPad have no Web MIDI. The browser asks once to allow MIDI access with SysEx; the page needs it to talk to the unit.

The page doesn't find the unit, or the unit doesn't answer

  • Use a USB cable that carries data (some only charge) and switch the unit on.
  • Close Components and other MIDI programs; on Windows only one program can use the unit at a time.
  • Firefox on Linux: when the unit restarted while the page was open (switched off and on, or updated by another program) and it no longer answers, quit Firefox completely and start it again. Reloading the page is not enough.

A flash stopped halfway, or the unit doesn't start

Switch the unit off, hold Scales + Note + Velocity and switch it on: it starts in its bootloader. Then flash again here, or flash Stock 1.2. A firmware update doesn't touch patches and sessions.
